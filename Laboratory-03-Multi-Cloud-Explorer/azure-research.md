# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's cloud platform, launched in 2010. It is deeply integrated with Microsoft's enterprise software ecosystem (Windows Server, Active Directory, Microsoft 365).

## Global Infrastructure
Azure infrastructure is built on **Regions** grouped into **Geographies**, each containing one or more **Availability Zones**, plus Azure's global edge network for content delivery.

## Cloud Management Console
The **Azure Portal** is the primary web-based management interface, complemented by Azure CLI, Azure PowerShell, and Azure Resource Manager (ARM) templates for infrastructure as code.

## Four (4) Core Services
1. **Azure Virtual Machines** – on-demand, scalable compute.
2. **Azure Blob Storage** – object storage for unstructured data.
3. **Azure SQL Database** – managed relational database service.
4. **Microsoft Entra ID (formerly Azure Active Directory)** – identity and access management.

## Three (3) Advantages
1. Seamless integration with existing Microsoft products (Windows Server, Active Directory, Microsoft 365, .NET).
2. Strong hybrid cloud support through Azure Arc and Azure Stack.
3. Enterprise-grade compliance and licensing benefits for existing Microsoft customers.

## Typical Enterprise Use Cases
- Organizations already running Windows Server/Active Directory migrating to a hybrid cloud.
- Enterprise line-of-business application hosting.
- Business intelligence workloads via Power BI and Azure Synapse Analytics.
