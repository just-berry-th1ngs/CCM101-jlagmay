# Automation Research

## Bash Script

A Bash script is a file that holds a list of commands. Running the file runs all the commands, so repeated tasks are done automatically. The first line, `#!/bin/bash`, is the shebang. It tells Linux to run the file with the Bash program.

## Variables

A variable stores a value, like a folder path, so I can use it many times in a script. It is easier to maintain because I change the value in one place. It also avoids typing mistakes when I would otherwise type the full path again and again.

## Cron Job

A cron job is a task that runs on a schedule, such as every night at 2:00 AM. Many cloud servers run without anyone watching them, so cron does the tasks without a person. This is faster, cheaper, and has fewer human errors. For example, it can run backups or clean old files from storage.
