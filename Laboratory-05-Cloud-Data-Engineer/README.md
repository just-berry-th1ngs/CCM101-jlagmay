# Laboratory 5 - Cloud Data Engineer

## Mission Overview
Deployed an S3-compatible object storage server (MinIO) using Docker on a KillerCoda Ubuntu playground, created a storage bucket, and uploaded a test file to simulate a cloud object storage proof-of-concept for a photo-sharing application.

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server (MinIO) using Docker.
- Access a cloud service via a web interface using port forwarding.
- Create a storage bucket and upload objects to the cloud.
- Document cloud storage operations using Markdown.

## Tools Used
- Docker
- MinIO (via `tobi312/minio` image)
- KillerCoda Ubuntu Playground
- GitHub

## Skills Learned
- Deploying containerized services with environment variables in Docker.
- Understanding Block vs. File vs. Object storage.
- Accessing web services running in a container via port forwarding.
- Managing S3-compatible object storage through a web console.
- Adapting to real-world dependency/deployment changes (Docker Hub image deprecations).
