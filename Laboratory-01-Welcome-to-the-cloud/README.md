# Laboratory Activity 1 - Welcome to the Cloud

## Mission Overview
This activity involved setting up a Linux user account, exploring the system environment, and building
a documented, version-controlled workspace using KillerCoda and GitHub.

## Objectives
- Access a Linux environment using KillerCoda
- Gather basic system information
- Organize files and directories
- Create and maintain a GitHub repository
- Document work using Markdown

## Activities Performed
- Created user jlagmay with home directory and sudo access
- Investigated system information (distro, kernel, CPU, memory, disk)
- Built a workspace folder structure
- Created and pushed a GitHub repository

## Linux Commands Used
- useradd, passwd, usermod, su
- cat, uname, lscpu, free, df
- mkdir, nano, ls
- git clone, git add, git commit, git push

## Skills Learned
I learned how to create and manage Linux users, gather system diagnostics, and use Git/GitHub for
version control and documentation.
